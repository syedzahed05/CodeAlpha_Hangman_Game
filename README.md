# CodeAlpha Hangman Game

A simple text-based Hangman game developed using Python as part of the **CodeAlpha Python Programming Internship**.

## 🎯 Project Overview

This is a console-based Hangman game where the player attempts to guess a randomly selected word one letter at a time.

The player is given a maximum of **6 incorrect guesses** to complete the word.

## ✨ Features

* Randomly selects a word from a predefined list
* Allows the player to guess one letter at a time
* Displays the progress of the word
* Tracks incorrect guesses
* Prevents repeated letter guesses
* Displays win and game-over messages
* Simple console-based interface

## 🛠️ Technologies Used

* Python
* `random`
* Strings
* Lists
* Loops
* Conditional statements

## ▶️ How to Run

Make sure Python is installed on your system.

Run the following command:

```bash
python hangman.py
```
